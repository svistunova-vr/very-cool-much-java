<summary>Задание</summary>

В банковских системах необходимо обрабатывать множество операций одновременно: проверка кредитной истории, расчет ставок, обновление балансов. Для обеспечения производительности и целостности данных требуются эффективные механизмы параллельной обработки.

**Задача:**

Реализовать систему асинхронной обработки финансовых операций с обеспечением потокобезопасности и управлением параллельным выполнением задач.

**Требования:**

* Реализуйте потокобезопасный счетчик для отслеживания количества операций по каждому типу продукта
* Обеспечьте атомарное обновление статистических данных в многопоточной среде
* Реализуйте асинхронную загрузку курсов валют из нескольких внешних источников
* Организуйте параллельное выполнение и комбинирование результатов
* Добавьте обработку таймаутов и fallback-механизмы при недоступности источников
* Создайте настраиваемый пул потоков для обработки фоновых задач
* Реализуйте механизм приоритезации задач (высокий приоритет для клиентских операций, низкий для аналитических)
* Реализуйте механизм безопасного обновления балансов клиентов
* Защитите операции списания/зачисления средств от состояния гонки
* Используйте различные механизмы синхронизации&#x20;
* Создайте систему обработки заявок с использованием очередей
* Реализуйте механизм равномерного распределения нагрузки между потоками-обработчиками
